# プレビュー画像の自動出力

Preview画面の左下にあるカメラボタンで、現在の撮影視点を記録します。記録済みのボタンは緑色になります。もう一度押すと、そのプレートの設定を上書きします。視点はプレートごとに1つです。

記録後に画面を回転・移動・拡大しても、撮影設定は変わりません。通常の「プロジェクトを保存」で3MFに書き込みます。設定の記録と削除はUndo／Redoに対応し、印刷設定やツールパスを変更しません。

カメラボタンの右クリックメニューには、次の操作があります。

- 記録した視点に戻す
- 撮影設定を削除
- 記録した設定でPNGを書き出す（スライス完了時）

CLIでは、撮影設定のあるプレートをスライスすると、G-codeと同じ場所に `plate_1.preview.png` などのPNGを自動保存します。

GUIの「G-codeをエクスポート」でも、撮影設定を記録したプレートはG-codeの保存成功後に、同じフォルダーへ `<G-code名の拡張子を除いた部分>.preview.png` を自動保存します。撮影設定がない場合はG-codeのみを保存します。画像生成に失敗した場合は警告通知を表示し、G-codeは保持します。

```sh
OrcaSlicer --slice 0 --outputdir /tmp/sliced project.3mf
```

画像を必要としない実行では、`--no-export-preview` を付けます。

```sh
OrcaSlicer --slice 0 --no-export-preview --outputdir /tmp/sliced project.3mf
```

PNGには、記録した位置・角度・投影方式・倍率・ピクセル寸法で3D表示を描画します。Line Typeの色分け、全レイヤー、すべての押出種別とSeamsを表示し、Travel／Wipe／Retract／Unretractは非表示にします。背景、ベッド、シェル、DynaPinオーバーレイも含みます。凡例、スライダー、操作用マーカーは含みません。

撮影設定は3MF内の `Metadata/orca_preview_capture.json` に保存します。印刷設定やプリセットには追加しません。カメラ位置・注視点はプレート原点からの相対座標です。組み込みベッドのアセットパスはリソースディレクトリからの相対パスで保存します。外部のカスタムベッド画像・モデルを使う場合は、そのアセットも実行環境から参照できる必要があります。

CLIの描画にはOpenGL 3.2以上と、GLFWがコンテキストを作成できる環境が必要です。画像生成に失敗した場合はプレート番号と理由を警告し、生成済みG-codeは保持します。PNGは一時ファイルへの書き込みが完了した後に置換します。失敗した場合、以前の同名PNGが残ることがあります。

## 検証記録（2026-10-17、macOS arm64 Release）

- アプリと関連テストのビルドに成功。撮影設定・3MF・DynaPinの17テスト195項目と、カメラ・非表示OpenGL描画の2テスト22項目に成功。
- GUIで記録、上書き、削除、Undo／Redo、視点復元、通常保存、3MF再読込、PNG出力を確認。記録後のズーム操作では撮影設定が変わらないことを確認。
- 同じ3MFからのGUI／CLI出力は3024×1566ピクセルで完全一致。PNG／SVGベッド画像、非正方形画像、透視／平行投影、プレート原点変更を確認。
- 撮影設定なし、`--no-export-preview`、ベッドモデル読込失敗はいずれもG-codeを保持して正常終了。読込失敗時はプレート番号と理由を標準エラーへ警告。
- DynaPin有効／無効の比較入力で、変更前後のG-codeは生成日時以外が一致し、スライス統計も一致。DynaPinオーバーレイを含むCLI画像を目視確認。
- 複数プレートの対応、メタデータの格納順変更、単一プレート書き出しは3MFテストで確認。GUIでの複数プレート並べ替え操作と、異なるGPU間の比較は未実施。

OpenGLテストはデスクトップのGUIサービスに接続できる環境で、次のように明示的に実行します。

