# ピン上の定着用サポート初層：仕様と変更理由

更新日: 2026-10-22。ピン専用インターフェース方式から定着用初層への変更、および外縁余白・設定参照先の扱いを記録する。

## 目的と仕様変更の理由

ピン上ではサポート材を取り外しやすくすることより、ピンに定着させて上のサポートを安定して造形することを優先する。ピン上面を仮想ビルドプレートとして扱い、最初の実サポート層だけに通常サポートの初層条件を適用する。実機での定着性改善は今後評価する。

会話での判断は次の順序で変わった。理由は設計上の意図であり、定着性を実測した結果ではない。

| 段階 | 採用した方針 | 変更・採用の理由 |
| --- | --- | --- |
| 初期 | ピン上をサポートインターフェースにし、冷却を止める | 反りを抑え、ピン上に定着させるため。2〜3層必要という仮説から、専用の固定2層ではなく既存の下部インターフェース層数を使うことにした。 |
| Z整合 | 初層下端をピン上面に合わせる | 層位置由来の隙間を残したままでは、密度や冷却を変えても直接定着できない。隙間は全ピン一律の固定0.15 mmとして扱わず、各ピンと実サポート層の位置から調整する。 |
| 現行の初層 | 通常サポートの初層を1層だけ生成する | インターフェースは通常、造形物との接触条件を調整するためのもの。今回はピンにサポートを定着させる目的なので、ビルドプレート上と同じ初層条件を使う方針に変更した。 |
| 外縁の補正 | 連続ピンの外側の端だけ1.2 mm縮める | 12.4 mmは隙間を含むピッチで、実幅10.4 mmのピン上面をそのまま表していない。隣接ピン間はつないでよいが、端では押出がはみ出ないようにする必要がある。 |
| 設定の参照先 | 開発環境の優先JSONをリポジトリへのシンボリックリンクにする | リポジトリの変更がGUIスライスに反映されず、古い設定コピーが優先されていたため。 |

## 現行仕様

対象は通常サポートと既存のDynaPin対応tree_slim・tree_strong・tree_hybrid。各ピンに着地する最初の実サポート層だけを定着用初層にする。

| 項目 | 使用する条件 |
| --- | --- |
| 層数 | 各着地部分の最初の1層。2層目以降は通常のサポート生成・冷却に戻る。 |
| 押出種別・材料 | `erSupportMaterial`、`support_filament`。造形物との接触に必要な通常インターフェースは維持する。 |
| 密度 | `raft_first_layer_density` |
| 足元の拡張 | `raft_first_layer_expansion`。ピン上面の造形可能範囲、モデルとの間隔、造形範囲、他ピンとの干渉で制限する。 |
| 線幅・押出量 | `support_material_1st_layer_flow`で既存の初層線幅を解決し、各部分の実際の層厚から押出量を求める。ベッド初層の層厚には置換しない。 |
| 速度 | `initial_layer_speed`。既存の体積流量制限などは引き続き適用する。 |
| 経路 | 機械X方向へ一方向に進む走査と造形順を維持し、通常初層の外周経路は追加しない。 |
| 冷却 | 対象の全押出経路で造形物冷却ファン0%を優先し、退出後は次の経路の通常制御へ戻す。先行起動・キックスタートが停止区間に入らないようにする。 |

これらは既存のプロセス設定を使用する。適用範囲は各既存設定に従い、密度・拡張量のオブジェクト上書きも反映する。下部インターフェース層数が0・1・2・3・−1のいずれでも、定着用初層は1層である。旧案の専用設定`landing_base_layers`・`landing_brim_width`・`landing_base_density`は追加しない。

## 生成とZの整合

`row`はZ方向、`col`はY方向で、ともに0始まりである。ピン上面とブロッカーのZ範囲は`DynaPin::blocker_z_range`を基準にする。

```text
pin_top_z = support_origin.z + row × pitch.row_z
blocker_z_max = pin_top_z
blocker_z_min = blocker_z_max − blocker_height_z
pull_z = pull_origin.z + row × pitch.row_z
```

支持領域のY中心は現行実装で`support_origin.y + col × pitch.col_y − 7.2` mm。引き出し用原点・接近・係合・離脱の補正値とは独立している。上段ピンのブロッカー下端を一律に0へ延長して、下段に必要なサポートを消してはならない。

1. ピン上面に着地する最初の実サポート層を特定する。
2. Z整合により初層下端をピン上面に合わせ、元の上端との接続を保つ。必要な場合は造形可能な層厚に分割する。
3. 足元を既存の初層拡張量で広げ、下記のピン上面の範囲と交差させる。同じ高さの連続ピンは結合し、拡張が共有境界を越えられるようにする。
4. 元の最初の着地領域を通常サポート・インターフェースから除去する。縮めた端の領域も元の通常経路として残さず、拡張領域とも重複押出ししないようにする。
5. 経路を線幅の半分だけ内側に置く。走査線の間にある小さな造形可能領域には、その領域内に1本の走査線を補う。
6. 着地の識別情報を押出種別とは独立して経路まで保持し、分割・流量調整・並べ替え後も速度とファン制御に使用する。

ホットエンド温度・ベッド温度・補助ファン・排気ファン、および短時間層の減速処理は変更しない。

## ピンの造形可能範囲と赤いボックス

`support_exclusion.blocker_width_y`はサポート除外領域の幅であり、赤いプレビューボックスもこの幅のまま。定着用初層の範囲だけに、任意項目`support_exclusion.landing_edge_inset_y`を適用する。省略時は0 mmである。

KP3Sではピッチ・ボックス幅が12.4 mm、片側の外縁余白が1.2 mm。同じ高さで実際に使用する連続N本の造形可能幅は`12.4 × N − 2.4` mmとなる。単独10.0 mm、2本22.4 mm、3本34.8 mmである。実幅10.4 mmに対して単独ピンでは片側0.2 mmの余裕を残す。これは会話で指定された片側1.2 mmを優先した値で、実幅いっぱいの10.4 mmに合わせた値ではない。

連続ピン間の共有境界には余白を設けない。途中に未使用ピンがある場合や高さが異なる場合は別の領域とし、それぞれの端に余白を設ける。押出中心線にはさらに線幅の半分を加味し、材料の幅を含めてこの範囲内に収める。
